# Free Higher English Revision — Scotland

A free, offline-capable revision web app for **Higher English** (Qualifications Scotland, formerly SQA), built for S5 pupils.

Live site: https://cazzam15.github.io/English/

- Reading for Understanding, Analysis and Evaluation (RUAE): own-words, word choice, imagery, sentence structure, tone, link and evaluation questions, plus the 5-mark final question
- Critical Reading: every text on the Scottish set text list valid from 2025–26, the 8-mark final question (2026–27 format) and critical essay skills for drama, prose, poetry, film & TV and language
- Portfolio–writing (one piece, max 1,300 words) and spoken language
- Quick quizzes, exam-style questions with self-marked marking points, worksheets, flashcards, essay plans, two RUAE mock papers with original passages, timed knowledge tests and a timed challenge

Progress is stored only in the browser (localStorage). Not affiliated with Qualifications Scotland.
As an Amazon Associate this site may earn from qualifying purchases.
